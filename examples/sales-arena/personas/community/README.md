# Community persona seed

Three seeded community personas to populate the Arena gallery on day one:

- **`influencer/`** — The Influencer: reach-first, LinkedIn DMs + Loom + voice notes, mid-market.
- **`engineer/`** — The Engineer: quantification-first, benchmarks + architecture diagrams + ROI sheets, enterprise.
- **`hardballer/`** — The Old-School Hardballer: phone-first, urgency + champion development, transactional mid-market.

Each is a complete persona pack per the SA-07-01 `.salesman.zip` format: `persona.yaml`, `system-prompt.md`, `bio.md`, `cadence.yaml`, `outreach/email/variant-{1..5}.md`, `proposals/starter.md`, `avatar.svg`, `README.md`.

All bio + system-prompt content is DNA-original. No real-person likeness, no copyrighted dialogue. Distinctness across the three is enforced by `SalesArena.Personas.Tests.CommunityPersonaPacksTests`.
