# Glengarry v1 Lead Pack

> *"The leads. The Glengarry leads."* — every persona in the Arena, after their first 24-hour scoring window

The flagship lead pack for the DNA Sales Arena. 200 fully-synthetic B2B prospects.

## What's in it

| Tier | Count | Description |
|---|---|---|
| `glengarry` | **20** | Premium leads with full firmographic intel: named contact, role, 2-3 intent signals (news, hiring, content engagement, mutual connections, press releases, leadership changes, etc.). These are the leads that *drip* to top-tier personas after each scoring window. |
| `cold` | **180** | Sparse-intel volume fodder. Company name + region; ~60% have a contact name; ~25% have a role. Levene will fire 47 of these off before lunch and most will bounce. |

## The Cadillac leads (a guided tour)

Each premium lead has narrative hooks the personas can ride. A few highlights:

- **L-0001 Yatzee Pharmaceutical** — new CFO + analytics-modernization mandate + hiring spree. The Cadillac.
- **L-0003 Riverbend Robotics** — Series C funded + predictive-maintenance budget. Moss bait.
- **L-0007 Quillstone Publishing** — newly-promoted CRO with a public 90-day data mandate. Fastest available close.
- **L-0011 Carbide Healthcare Networks** — new CDO + value-based-care initiative + 5 senior data-eng roles posted. The biggest cycle on the board.

See [`leads.json`](./leads.json) for the full pack. Every Cadillac lead has a `notes` field naming the persona it's designed for.

## Safety properties (enforced by the schema)

- **All domains** use `.example`, `.test`, or `.invalid` (RFC-reserved — guaranteed never to collide with real domains).
- **All phone numbers** use the `555-NNNN` reservation (North-American fictional prefix).
- **All contact names** are diverse and intentionally uncommon combinations to avoid real-person collisions.
- **`synthetic: true`** is a hard-coded marker in the pack header. Real-data packs (SA-06-06) use a different schema id entirely.

After SA-02-02 (Lead Pool) lands:

```bash

dna-arena contest start --name "Glengarry-Steak-Knives" --personas roma,levene,moss,aaronow --hours 1 --time-compression 60
```

Watch the bell. Watch the Cadillac drip.

## How to regenerate or extend

The cold leads are deterministically generated by the seeded Python script at
[`../tools/generate-glengarry-v1.py`](../tools/generate-glengarry-v1.py):

```bash
python3 examples/sales-arena/lead-packs/tools/generate-glengarry-v1.py
```

The 20 glengarry leads are hand-curated at the top of that script — edit the
`GLENGARRY_LEADS` array, re-run, commit. The seed (`20260517`) keeps the cold-
lead generation deterministic so diffs stay reviewable when you change cold-
lead tables.

## Validate

A pack should pass:

```bash
python3 examples/sales-arena/lead-packs/tools/test-lead-pack.py examples/sales-arena/lead-packs/glengarry-v1/leads.json
```

After SA-04-03 (CLI) ships, the same checks run via:

```bash
dna-arena leads validate examples/sales-arena/lead-packs/glengarry-v1/leads.json
```
