# Writing And Publishing Example Pack

This public pack covers proposal drafting, content repurposing, publishing
planning, and writing assistance as deterministic offline examples.

## Run

```bash
dotnet run --project samples/writing-publishing -- --smoke
```

Expected result: JSON with `"status": "passed"`, `exampleCount` equal to `4`,
and public result envelopes for each example.

The pack does not expose private brand memory, continuity systems, scheduling
automation, analytics loops, or hosted publishing services.
