# DotNetAgents Open Core v0.1.0-preview

**Headline:** Build agentic .NET systems. Operate them with DNA Factory when
you need a governed factory.

## What Shipped

| Repository | Tag | What it is |
| --- | --- | --- |
| [dotnetagents](https://github.com/jim-finlon/dotnetagents) | `v0.1.0-preview` | Open .NET agent framework |
| [dotnetagents-plugins](https://github.com/jim-finlon/dotnetagents-plugins) | `v0.1.0-preview` | Optional adapters |
| [dotnetagents-examples](https://github.com/jim-finlon/dotnetagents-examples) | `v0.1.0-preview` | Runnable examples + public docs |

## What DotNetAgents Is

DotNetAgents is the open .NET framework for building observable, tool-using,
multi-agent systems. Clone the public repos, run an example, and build with
your own providers and data — without DNA private services.

## What DNA Factory Is

DNA Factory is the commercial operating layer: governed autonomous delivery,
labs, eval evidence, credential custody, certification receipts, and hosted
operations. Public examples may mention the upgrade path; they do not ship the
private control plane.
